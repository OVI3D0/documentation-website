# Understanding results

After [running a workload]({{site.url}}{{site.baseurl}}/benchmark/user-guide/working-with-workloads/running-workloads/), OpenSearch Benchmark produces a series of metrics. See the following reference pages for details:

- [Summary report]({{site.url}}{{site.baseurl}}/benchmark/reference/summary-report/) --- How metrics are reported at the end of each test run, including throughput, latency, and service time.
- [Telemetry devices]({{site.url}}{{site.baseurl}}/benchmark/reference/telemetry/) --- How to enable telemetry devices for additional insights like JVM stats, node stats, and segment statistics.
- [Metrics reference]({{site.url}}{{site.baseurl}}/benchmark/reference/metrics/) --- Detailed information about metric keys and metric records.
